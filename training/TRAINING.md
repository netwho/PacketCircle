# PacketCircle — Quickstart Training

This repository contains the training material for the **PacketCircle Quickstart Training** — a hands-on introduction to PacketCircle, the open-source Wireshark plugin for network traffic visualization and protocol intelligence.

## What This Training Covers

- Installation on macOS, Linux, and Windows
- Interface walkthrough and the WYSIWYF workflow — What You See Is What You Filter
- Selecting, filtering, and drilling from conversation to packet level
- Protocol deep-dives across 20+ protocols — HTTP, TLS, DNS, Kerberos, SMB, SIP, ARP, Telnet, and more
- Wi-Fi monitoring mode for wireless environment analysis
- Integration with ntopng for traffic classification
- Integration with Malcolm and Arkime for full packet reconstruction and IDS correlation
- A complete security incident walkthrough using a real lab capture
